# Il Dolce Far Niente plugin

This plugin installs and updates Il Dolce Far Niente in your project. It adds a
single `install` skill that runs the `il-dolce-far-niente` npm installer, which
writes AI Blueprint's gated feature loop (`/feature`, `/implement`, `/check`,
`/audit`, `/complete`), parallel `/avengers` builds, Matt Pocock's engineering
skills and per-role model settings into the repository, where every teammate
and every coding agent sees the same files.

Ask your agent to "install Il Dolce Far Niente" in the root of a scaffolded app,
approve the command it shows, restart the session, then run `/onboard`.

Requirements: Node.js 22 or newer, a Git repository with a scaffolded app.
